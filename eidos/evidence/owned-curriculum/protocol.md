# Original relational curriculum: one bounded synthetic diagnostic

This is implementation and from-scratch training on newly authored finite worlds. The purpose is to establish what the current original question-conditioned architecture can learn and where it fails. It is not another use of any consumed real comparison, an independent natural-language benchmark, or a LAYA/JEV evaluation.

The current published architecture is frozen at `c661d541cf0c8c8cba41c4a682a31a4b36ac0fcb`. Only a new original corpus generator and its focused tests may be added for this stage. No changes to the neural scorer, trainer, artifact decoder or service based on held-out outcomes belong to this attempt.

Thirty training worlds and six development/six evaluation worlds each provide twelve tasks: two each for color retrieval, color-to-entity binding, binary grounded propositions, heavier/lighter comparison, two-step following/color lookup, and an explicitly stated anchored mass rubric. Each world has four entities, complete explicit atomic facts, four colors and finite masses/relations. Candidate IDs/order are administrative and independently shuffled. Contexts name the entity in every atomic fact. Mass intervals and numeric anchors are stated explicitly.

Role-specific proper names, question templates and fact-rendering templates do not overlap. Underlying worlds/groups are disjoint, with exact checks and explicit limits: all roles share the same tiny ontology/generator, and the joint wording/name shift does not isolate each source of error. Each counterfactual pair is one source group, giving only 15/3/3 groups; do not treat individual rows as IID or report row-wise confidence intervals. Following twice on a four-cycle cannot distinguish forward/reverse directions, so the relation family does not establish general directional graph reasoning. Test generation code is visible. No pristine hidden-source, paraphrase-family independence or real-domain generalization is claimed. Private oracle ledgers preserve typed facts and supervision without entering model features.

The fitting recipe is fixed before any new quality result: dimension 12, hidden 16, Adam float64, learning rate 0.005, seed 113, existing clipping/L2, training-only vocabulary and the final checkpoint. Epochs are selected only by the exact training-only work estimate: use the largest of the predeclared counts 6, 4, 2 that fits the existing one-billion-work bound; refuse fitting if none fits. This rule is frozen before preflight or model execution and does not read quality or losses. There is one fit; no quality-selected checkpoint, hyperparameter selection, refit or retry. Limits are not widened to obtain a result.

Execution roles are separate cleared offline mount/PID/network namespaces with read-only staged pins. Generation sees only original source; resource preflight and fitting see only training JSONL and provenance; prediction sees the frozen fitted artifact and requests, without oracle/target labels; scoring sees predictions and labels without model weights. The train fit uses at most 600 CPU/900 elapsed seconds and 768 MiB address space; other roles use 120 CPU/180 elapsed seconds and 768 MiB. These are per-process controls plus parent watchdogs, not an aggregate cgroup guarantee. No installs, downloads, GPU, paid compute, native reference, real corpus, existing keys/configuration, private repository or proprietary service are included.

The one prediction pass covers training, development and evaluation requests so training success can be distinguished from generalization. Score once after complete predictions. Report count, forced-choice/anchor accuracy, NLL, Brier and score expectation absolute error by role, head and task family where available. Include the uniform randomized expected accuracy implied by candidate count; this is an analytical baseline, not an independently trained competitor. Record all poor outcomes. Do not reuse the old 4/10 fixtures or any historical benchmark to tune this experiment.

Tests must check labels against independently parsed rendered facts and hand-computed worlds, role/group/template separation, opaque-ID/order invariance, option/rubric completeness, truth/polarity balance, reproducibility, bounds, symlink/no-overwrite and private output permissions. Mechanical checks and synthetic accuracy do not certify quality, calibration, data rights or production readiness.

All predictions remain uncalibrated and review-only with no action authority. No model promotion, production deployment or merge is included. The next architecture/data decision must be framed as adaptive to these results and evaluated with new appropriate data. `mission_complete=false`; `production_certified=false`.
